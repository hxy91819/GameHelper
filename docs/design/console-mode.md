# 主机模式视觉契约

主机模式采用适合电视观看的独立深色布局，沿用 A / Studio 的淡紫品牌色与原始 G 标识几何。海报和所选游戏名称是视觉主体；普通桌面库和统计页仍遵循 [Studio 契约](../architecture/studio-visual-contract.md)。

## 色彩与层级

页面 `#101116`，面板 `#191A22`，操作行 `#222330`，边框 `#3A3548`；正文 `#F3F0F7`，次级文字 `#B7B0C4`，强调色 `#BCA3E5`。选中行使用深紫底和淡紫边框，保存等主操作使用淡紫底配深色文字；禁用项明确弱化，正文与状态仍保持可读对比度。

所有资源局限于主机窗口，桌面选择浅色时也不会覆盖主机配色。共享画刷冻结，每个窗口/Dispatcher 创建自己的样式。按钮保留悬停、键盘聚焦、按下与禁用反馈，没有持续背景动画。

## 主页与详情

- 顶部显示原品牌标识、连接状态和当前列表数量；大标题展示所选游戏，摘要展示时长、手柄支持与最近游玩。长名称省略并提供完整提示。
- 分类页签以淡紫底和边框标明当前页签；搜索入口与分类分开。
- 使用已有缓存横图作为低透明度渐隐背景，缺图不影响浏览；切换选择时不重复解码相同图片，不引入额外网络请求或模糊特效。
- 海报保持真实 2:3 比例，在紧凑窗口根据实际滚动视口等比缩放；外层卡片维持 244 DIP 宽，沿用 L2/R2 按可见屏翻页。名称、时长、支持标签完整处于可视区域，缺封面显示首字符。
- 选中项用描边、底色和轻微抬升区分。手柄支持信息仍有中文文字，不仅依赖颜色。
- 详情将手柄说明和启动配置分组；正文单独滚动，启动/回到游戏、设置和返回等操作固定在底部。
- 真正空库、分类无结果与搜索无结果分别说明原因。

## 菜单与设置

系统菜单、游戏设置、二次确认、屏幕键盘和评分使用统一浮层，面板最大宽度 880 DIP。设置行左侧显示名称和说明，右侧显示开关或倍率状态；保存、重载、取消层级明确，长路径放在次级说明中。

内容可滚动，手柄操作提示及处理中/错误反馈固定在底部；选中行自动滚入可见区域。原有保存冲突保护、退出游戏与电源操作二次确认、按键语义均不变。

底部提示按层级分行：主要操作使用正文色，全局模式组合键另起一行使用次级文字，避免小屏换行时把组合键拆成孤立尾句；详情中的系统菜单提示合并，保留结束游戏的确认说明。

## 视觉验收

使用隔离数据、假后端与现有本地图片，真实 WPF 渲染并目视检查 1920×1080、1280×720 和 960×650。至少覆盖主页、详情、系统菜单、游戏设置、末行滚动、长中英文名称、缺图及三种空态。验证不得保存真实配置、启动/停止真实游戏或切换 HDR、DS4Windows、CE。

本轮截图验收修正了小屏支持标签裁切、海报缩放比例、详情操作区被正文挤走，以及浮层遮挡帮助提示的问题。自动化断言检查对比度、比例、卡片边界、固定提示和末项可达；测试通过仍需截图目检。
