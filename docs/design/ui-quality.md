# UI 品质标准

## 设计目标

以私人游戏典藏为视觉主题，让游戏海报承担内容表达，界面提供安静、有秩序的背景。参考 [Awwwards](https://www.awwwards.com/about-evaluation/)、[Webby 评审标准](https://www.webbyawards.com/judging-criteria/) 与 [FWA](https://thefwa.com/) 对设计、体验与创意的要求，转化为本地桌面产品可检查的标准。此处是产品内部质量标准，不代表获得或通过外部奖项评审。

## 视觉契约

- 深色背景 `#101413`、侧栏 `#141A18`、面板 `#19211E`；暖白 `#F0F2EB` 为正文，`#A4B2A9` 为次级文字。
- 薄荷 `#B8E8CE` 用于主操作、选中轮廓与图表。深色主题中的浅色主按钮必须配深色文字，不能依赖降低整块透明度表达悬停。
- 浅色背景 `#F4F6F1`、侧栏 `#EAF0E8`、面板白色；正文 `#20352A`、次级文字 `#52695A`、强调色 `#226242`。主操作以深绿底配白字；海报状态角标保持深底浅字。两套调色板的主要文字与主按钮对比度至少 4.5:1。
- 30px 页面标题、20–22px 详情标题、14px 正文、11–12px 辅助信息。英文索引仅作辅助，主要操作保留中文。
- 6–8px 小圆角、1px 边框、明确的面板留白。避免大面积发光、无意义动效和遮盖内容的装饰。
- 主视觉是 2:3 游戏海报；缺图时显示首字与轻量轨道，维持完整构图。Logo 直接使用品牌矢量源。

## 交互与验收

- 启动和保存固定在详情栏底部，详情内容单独滚动；1120×740 最小窗口仍能访问主操作。
- 导航、安装分组、功能筛选与视图切换均有选中反馈；按钮保留悬停、按下、禁用和键盘聚焦反馈。
- 列表行宽跟随可用内容区，不能把 ListBox 外宽强加给行而挤掉状态。
- 游玩档案的指标、图表、表格与日历使用统一色彩，保留读数、日期和无数据提示。统计不改变业务口径。
- 验证必须使用真实 WPF 渲染，覆盖网格、列表、搜索空结果、最小窗口、启动选项、统计全历史和日历。使用隔离数据目录与本地缓存，截图模式不启动游戏、不保存配置。

## 浅色主题实现与验收

`Themes/Dark.xaml`、`Themes/Light.xaml` 提供相同的语义资源键，视图使用动态资源；`DesktopTheme` 切换资源字典并使自绘图表重绘，`ThemeBrushes` 为图表和原生弹窗读取语义颜色。图表悬停提示每次显示时获取当前主题；模态弹窗在打开时采用当前主题。

主题偏好独立原子保存；保存失败不会产生一半已切换、一半未保存的状态。测试覆盖偏好与游戏配置／草稿隔离、重启恢复、缺失／损坏／未知值回退、保存失败不切换、资源键一致与文字对比度。

真实 `--snapshot` 在同一个进程中先按当前偏好生成原有截图，再切换到另一套主题生成 `light/` 或 `dark/` 子目录，最后恢复原主题并输出 `theme-restored.png`。切换探针不保存主题偏好，不修改游戏配置；两种主题都覆盖列表、网格、最小窗口、空状态、统计／日历及可选的目录导入弹窗。

输入框选中文字显式绑定主题正文色，沿用正文与选中底色的 4.5:1 对比度检查。原生焦点选区未被离屏窗口截图捕获，不作为截图已覆盖的状态；不保留无实际选区的伪验证截图步骤。
