# 正常显示开机自启窗口，废弃后台无焦点启动

2026-10-21 用户决定停止探索“不影响前台应用的后台启动”。开机自启、桌面快捷方式和部署重启统一直接运行 ConsoleHost，正常显示交互窗口，保留彩色界面与现有 Windows Terminal 宿主判断；不再发布被动 Launcher 或保留就绪事件握手。

此前围绕隐藏、最小化和不激活显示的多轮尝试增加了窗口交接与测试复杂度，用户更重视可靠的正常开机启动。因此无焦点后台启动是已废弃的产品方向，不能仅以避免抢焦点为由重新引入；如用户未来明确提出新的要求，再重新讨论。旧版本桌面 Launcher 入口在成功部署后迁回 ConsoleHost，自启注册由新实例同步。
