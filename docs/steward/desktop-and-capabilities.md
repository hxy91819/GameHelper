## 关键决策

- 2026-11-12 私人收藏需要密码：首次进入设置 4–32 位 ASCII 字母或数字（不区分大小写），之后每次进入桌面/主机模式都验证，离开分类即锁定；密码只存本机 PBKDF2-SHA256 加盐哈希，不进 SQLite、数据库备份或 sync；未设置密码时拒绝新增私人标记，已有标记不受影响。原因：用户要求“私人收藏改成需要密码才能用”。影响：桌面游戏库、主机模式、私人收藏保存门。

- 2026-11-09 派发默认 auto 权限：simple 为 DeepSeek Harness 4.1 Flash/max，medium 为 Codex 6.1 Sol/medium，complex 为同模型/high；用户本轮指定，覆盖旧约定。

- 2026-11-05 评分交互修订：点星只选分数并保持窗口／浮层打开，允许继续写想法，再由「保存」／「提交评分」一起提交并关闭；替代 10-30 点星即保存的约定。原因：用户反馈先打星就关闭，无法继续写评论。影响：桌面和主机评分界面。

- 2026-10-30 桌面与主机评分均展示横排五颗星，左到右 1–5 星，用户明确点星即提交；想法可先填后一并保存，手柄左右只选星、确认再提交。托盘按实际注册证据排查，专用高对比图标替换通用系统图标，不修改 Windows 通知区偏好。原因：用户本轮反馈。影响：评分 UI 与后台托盘入口。

- 2026-10-26 旧 Console 交互界面不再维护，界面全部围绕 WPF；不做存档位置猜测。原因：用户确认。影响：全部阶段。
- 2026-10-26 HDR 按显示器允许；未允许显示器跳过 HDR 并降级 DDC 游戏预设。原因：仅接电视时需 HDR。影响：HDR、DDC。
- 2026-10-26 游戏非空 `speedHotkeys` 整体替换全局默认，不逐键合并。原因：最少歧义。影响：阶段 7。
- 2026-10-27 扫描每次全量遍历，只收起已在库与忽略目录，不做增量跳过。原因：新游戏就出现在常扫目录。影响：阶段 8。
- 2026-10-27 无参数启动 ConsoleHost 直接拉起 WPF 游戏库，不兼容旧交互行为；删除 migrate。原因：用户原话。影响：阶段 9.1。
- 2026-10-27 子线程交付经管家验收后由管家直接合并 main，Windows 实机验证改为合并后检查。原因：用户原话“所有的都是你自己合并就行”。影响：全部阶段。
- 2026-10-27 本目标由管家编排：改动经 BB 子线程派发，管家只判断、验收、维护工作簿。原因：用户指示。影响：后续全部阶段。
- 2026-10-28 主倍速编辑从文本框改为滑块（0.1–10×、步进 0.1，旁边即时显示）；滑块只会读出收拢值，未拖动不改写超区间旧配置。原因：用户要求“倍速改成滑块，可以选择倍速多少”。影响：游戏库设置面板。
