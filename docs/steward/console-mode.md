## 关键决策

- 2026-10-29 本目标沿用管家编排：改动经 BB 子线程派发，管家验收后直接合并 main，Windows 实机验证合并后检查。原因：沿用 desktop-and-capabilities 约定。影响：全部阶段。
- 2026-10-29 不引用 xerj（已撤回，试验留在分支 feat/xerj-search）。原因：用户确认它不能在 GitHub 发现方案。影响：阶段 2。
- 2026-10-29 现成能力优先以组件（NuGet/库）引入，不行再以代码引入。原因：用户原话。影响：阶段 2–5。
- 2026-10-29 Windows 实机验证不阻塞开发：按合理预估先做，最后集中验证再调整。原因：用户原话。影响：全部阶段。
- 2026-10-29 主机模式 v1：原型布局 A；部分/不支持启动前确认、未知不提示；入口为托盘与游戏库按钮，另有"启动即进主机模式"开关（默认关）；从主机模式启动的游戏退出后恢复主机模式。原定不做组合键、设置只读，由下方实机反馈要求覆盖。原因：用户授权管家决定。影响：阶段 4b。
- 2026-10-29 用户实机反馈：修复深色背景中文字不可读、选中卡片纵向拉伸；补充前台手柄组合键切换桌面/主机模式，以及主机模式编辑游戏 HDR、DS4Windows、倍速。原因：用户截图与新要求。影响：主机模式增补。
- 2026-10-29 管家可按任务并行派发，默认使用 GPT-6.1 Sol、medium；由管家验收并收敛打包。原因：用户明确指示。影响：后续任务。
- 2026-10-29 用户正在玩游戏，测试优先使用隔离数据、离屏窗口，不触碰真实 HDR、DS4Windows、倍速或游戏进程；更新前核对续算与恢复影响。原因：用户要求尽量不影响游玩。影响：本轮验证与交付。
- 2026-10-29 用户随后允许当前时段进行测试验证；仍用隔离数据和替身程序，不改变真实游戏设置。退出游戏后须恢复 GameHelper 前台与焦点，同时覆盖桌面和主机模式。原因：用户补充要求。影响：退出恢复与实机验收。
- 2026-10-29 L2/R2（LT/RT）按当前可见的一屏海报翻页，L1/R1 保留分类页签；□ / X 在主页、详情直接打开游戏自动化设置，键盘/评分中的原辅助操作保留，结束游戏移至系统菜单并保留确认。原因：用户反馈后面的游戏难选、需要快速设置入口。影响：主机手柄导航。
- 2026-10-29 主机 UI 按沉浸、克制的深色电视游戏库打磨，沿用现有淡紫品牌与本地海报；强化选中项、信息层级和统一菜单样式，同时保留已定手柄操作。原因：用户认为当前主机界面粗糙，授权直接美化。影响：主机视觉与小尺寸布局。
- 2026-10-29 输入用 SDL3-CS（关增强报告）+ Playnite MIT 桥接；手柄数据只接 Steam appdetails，Steam 未标注显示为不支持、无 AppID 为未知、手动设置优先。原因：调研结论，可撤回。影响：阶段 4–5。
