# 配置重构兼容契约

修改配置 codec、校验器、归一化或保存入口时，按本契约验收。纯重构以改动前实现为基线；有意改变契约时，在 PR 中逐项说明变化及迁移影响，单独验收。

## 保存与写回

- 分别比较 `Read`、空修改 `Change(_ => {})`、设置局部更新及 Catalog 修改的接受／拒绝范围。校验逻辑合并后，各入口原有的保存范围仍须保持；其他段的历史无效值不能因此新增为无关修改的保存阻断。
- 对相同输入和操作，比较旧、新实现写回的完整字节，包括字段顺序、列表缩进、缺省字段省略、数值与时间戳格式和文档结束符。空修改的比较对象是旧实现的写回产物；旧实现已有的注释丢弃或规范化不等于原文件字节保留承诺。
- 用固化样本及旧版期望产物锁定上述契约，覆盖完整字段、缺省值、未知字段和历史无效可选值；期望字节独立保存，不由被测新版序列化器生成。验证局部更新保留未修改字段、拒绝时文件不变，并让旧版读取新版产物检查回滚兼容；仅新版往返成功不足以证明兼容。

## 校验与诊断

- 同时比较有效性、错误、警告和条目计数；诊断文案、字段定位与条数属于兼容比较范围。共享值校验仍按[依赖方向](./dependency-direction.md)分层，YAML 适配层负责结构／类型诊断及其既有呈现契约。
- 对语法可解析的文档，逐段累计独立错误；某段为 null、类型错误或无法转换时，仍校验其他可独立检查的段。只有无法继续解析文档的语法错误才终止整份校验。用一份同时含多个段错误的样本断言完整诊断，避免首错返回掩盖后续问题。
