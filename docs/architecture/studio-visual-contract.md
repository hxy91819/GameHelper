# A / Studio 视觉契约

游戏库和游玩档案以 A / Studio 原型为几何与样式基准；不把 B 的窄侧栏或 C 的杂志布局混入产品。明暗主题共享 A 的结构，深色只替换原型已有的深色配色。真实数据、可用设置入口及原型的设计切换条不要求复制演示内容；原型的设计切换条不进入产品。

| --- | --- |

| 主内容 | 左上 (246,108)；宽 983；标题 30px / 600，行高 45 |
| 主栏与详情 | 间距 27；详情宽 252，顶部与 hero 对齐 |
| 继续游戏 | (246,202)，704 × 243，圆角 14；横图 center 42%，三段深色渐变 |
| 详情 | (977,202)，header 高 118；内部边距 21；主按钮在常用开关下方，完整表单为独立二级面板 |
| 海报 | 4 列；宽 164、高 246，保持 2:3 竖版比例；列距 16、行距 19；圆角 9 |
| 字段工具 | 搜索框高 38；海报首行 y=586 |

1100px 以下按原型收窄到175px侧栏、23px内容边距、220px详情与3列海报；海报高度始终按实际列宽的1.5倍计算；1450px以上hero高295。外层页面统一处理预览纵向滚轮，避免内层 ListBox、DataGrid 和 ScrollViewer 截断事件；横向滚动条保持可用。右侧详情和周摘要以未平移的锚点计算吸顶位移，限制在视口高度内；右侧局部滚动在边界交还整页，海报和统计区域仍滚动整页。页面整体滚动，低频配置不挤占右侧详情主结构。英文 eyebrow 标签以明确字距绘制；不为匹配演示值修改真实统计。

桌面窗口最小尺寸为 960×650 DIP，让窄屏布局在真实窗口中可用。搜索、类型和安装状态筛选后的继续游戏仅来自当前可见结果；无选择时隐藏详情。真空库、搜索无结果及筛选无结果分别说明原因，并提供添加游戏、清除搜索或查看全部收藏的恢复操作。

详情长名称最多两行，悬停显示全称；正文和周摘要在右栏内部滚动，启动及设置入口固定在右栏底部，随右栏吸顶但不被长名称和低频设置挤出视口。运行中、启动中与缺少启动入口分别给出可理解状态。开关视觉轨道仍为 30×17，外层透明命中区域为 42×28，并有悬停、键盘焦点及禁用反馈。

年度日历保留七行与全部周列；可用宽度不足时等比缩小格距到当前宽度，绘制与鼠标命中使用同一格距，不靠横滚隐藏年末日期。表单选择框、日期输入及日期弹层共用 `Themes/FormControls.xaml` 的明暗主题资源，保留 WPF 的选择、日期输入及月／年／十年导航语义。

## 品牌的唯一几何源

`GameHelper.Desktop/Assets/gamehelper-logo.svg` 保留原型 `const logo` 的原始两个 SVG path、`viewBox="0 0 64 64"` 和 `#ac94d7` 播放标记。主体使用 currentColor：浅色为 #202020，深色随原型主题前景色。不得凭印象重画、重排三角或把实际笔画包围盒撑满图框。

`scripts/export-brand.ps1` 从该 SVG 生成 `Brand.xaml`、512px 透明 PNG 与 16/24/32/48/64/128/256px ICO。WPF DrawingImage 通过透明64px画布保留原SVG留白；侧栏以同一Geometry在34px画布显示。测试验证路径、颜色、viewBox及透明边界等值。

## 视觉验收

必须实际打开最新原型，按相同内容视口对照原生截图，并覆盖有图、缺图、空库、搜索空态、最小窗口和明暗主题。构建和逻辑测试不能代替此验收。`--snapshot` 在沙盒中可配 `GAMEHELPER_TEST_VIEWPORT=1280x720`；该开关只在 `GAMEHELPER_DATA_DIR` 存在时生效，截取内容视口并排除离屏窗口的非客户区边框。

浏览器 Skia 与 WPF 的文字抗锯齿、字重插值及110px位图边缘覆盖不同；Logo 的矢量路径、颜色与画布需完全相同，不将位图逐像素差异宣称为100%相等。2026-10-31 商业化品质审查将浅色次级文字从原型的 #777875 微调为 #6E706D，统一正文、操作及次级信息至少 4.5:1 的对比度门槛，覆盖页面、侧栏和输入底色；保留 Studio 布局与品牌几何。
