# A / Studio 视觉契约

游戏库和游玩档案以 A / Studio 原型为几何与样式基准；不把 B 的窄侧栏或 C 的杂志布局混入产品。明暗主题共享 A 的结构，深色只替换原型已有的深色配色。真实数据、可用设置入口及原型的设计切换条不要求复制演示内容；原型的设计切换条不进入产品。

## 品牌的唯一几何源

`GameHelper.Desktop/Assets/gamehelper-logo.svg` 保留原型 `const logo` 的原始两个 SVG path、`viewBox="0 0 64 64"` 和 `#ac94d7` 播放标记。主体使用 currentColor：浅色为 #202020，深色随原型主题前景色。不得凭印象重画、重排三角或把实际笔画包围盒撑满图框。

`scripts/export-brand.ps1` 从该 SVG 生成 `Brand.xaml`、512px 透明 PNG 与 16/24/32/48/64/128/256px ICO。WPF DrawingImage 通过透明64px画布保留原SVG留白；侧栏以同一Geometry在34px画布显示。测试验证路径、颜色、viewBox及透明边界等值。

## 视觉验收

必须实际打开最新原型，按相同内容视口对照原生截图，并覆盖有图、缺图、空库、搜索空态、最小窗口和明暗主题。构建和逻辑测试不能代替此验收。`--snapshot` 在沙盒中可配 `GAMEHELPER_TEST_VIEWPORT=1280x720`；该开关只在 `GAMEHELPER_DATA_DIR` 存在时生效，截取内容视口并排除离屏窗口的非客户区边框。

浏览器 Skia 与 WPF 的文字抗锯齿、字重插值及110px位图边缘覆盖不同；Logo 的矢量路径、颜色与画布需完全相同，不将位图逐像素差异宣称为100%相等。Studio 次级文字原色 #777875 对白色约4.43:1，按明确的原型还原要求保留；主文字与操作文字继续守住4.5:1测试门槛。
